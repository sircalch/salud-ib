# Demos 3D de salud e ingeniería biomédica

Demos interactivas en el navegador para aprender medicina, enfermería, fisioterapia e ingeniería biomédica con anatomía real en 3D.

**Ver en línea:** https://sircalch.github.io/salud-ib/ · [Español](https://sircalch.github.io/salud-ib/es/demos/) · [English](https://sircalch.github.io/salud-ib/demos/)

Parte de **Andrés Monreal Ciencia** — https://sircalch.github.io/

## Demos

| Demo | Área |
|---|---|
| El corazón eléctrico | Medicina |
| La luz que mide el oxígeno (pulsioxímetro) | Ingeniería biomédica / Enfermería |
| Gota a gota (venoclisis) | Enfermería |
| Cómo respiras | Medicina |
| La rodilla como palanca | Fisioterapia |
| Válvulas y ruidos del corazón | Medicina |
| Marcha paso a paso | Fisioterapia |
| Dentro del ventilador | Ingeniería biomédica / Enfermería |
| Tomar la presión arterial | Enfermería |
| El desfibrilador (DEA) | Medicina |
| El ECG de 12 derivaciones | Ingeniería biomédica |

Material educativo: no es consejo médico. Las señales fisiológicas son simulaciones didácticas.

## Cómo se actualiza

El código fuente vive en el repositorio del sitio académico. Este repositorio se genera con `tools/sync-salud-ib.py` y se publica con GitHub Pages desde la rama `main`.
